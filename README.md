# SMARTDINE

SMARTDINE is a project space for building a smarter dining experience. This repository is the starting point for its product goals, design, and implementation.

## Project goals

- Make it easier to discover and choose meals.
- Keep the dining experience simple for both guests and staff.
- Grow the project in small, documented steps.
