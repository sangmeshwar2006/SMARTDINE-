# SMARTDINE Product Brief

## Working idea

SMARTDINE should help diners decide what to eat and make the meal ordering experience straightforward. This is an initial direction, not a finalized product specification.

## First user flow to explore

1. A diner opens the menu.
2. They browse or filter available dishes.
3. They review dish details, including price and dietary information where available.
4. They choose dishes and submit an order, if ordering is in scope.

## Questions to settle before implementation

- Is the first version for a single restaurant or many restaurants?
- Will diners order and pay in the app, or only browse the menu?
- Who manages menus, prices, and availability?
- Which dietary labels and languages are needed?
- What devices and deployment platform should the first version support?

## Suggested first milestone

Agree on the user flow and data needed for each dish. Then choose the application stack and build one complete, testable flow before adding optional features.
